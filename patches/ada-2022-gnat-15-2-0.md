# Ada (2022, GNAT 15.2.0)

## Summary
Adjust the install flow for the current Alire crate layout and fetch the required libgpr patch from a stable source.

## Changes
- Mapped the generated `gnatcoll` import to `gnatcoll_core`.
- Replaced unconditional libgpr patching with a helper that checks for the patch file and matching cached sources.
- Applied the patch only when the target file is present and still needs it.
- Downloaded the required libgpr patch directly from Debian Sources instead of resolving and unpacking a Launchpad source archive.

## Notes
- This avoids `imported project file "gnatcoll" not found` and skips cleanly when the cache layout differs.
- The fixed Debian Sources URL avoids Launchpad download timeouts while preserving the same patch.
